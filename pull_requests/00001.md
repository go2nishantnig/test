### Add PyTorch transformer starter

This PR adds a minimal, end-to-end PyTorch GPT-style starter project including:
- Simple whitespace/punctuation SimpleTokenizer
- Dataset builder (block-level LM dataset)
- GPT-like model implementation using nn.MultiheadAttention
- Training script (train.py) with checkpoint saving
- Generation script (generate.py)
- Config file (config.yaml), requirements, README, and helper script (scripts/train.sh)

### How to test:
1. Create a small data file at data/text_corpus.txt (a tiny sample is fine).
2. Create a Python virtualenv and install deps: `pip install -r requirements.txt`
3. Train: `python train.py --config config.yaml`
4. Generate: `python generate.py --ckpt checkpoints/ckpt.pt --prompt "Hello world"`
